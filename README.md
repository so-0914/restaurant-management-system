## Installation & Setup Instructions:

#### Clone the Repository:
  
###### Bash
git clone [https://github.com/so-0914/restaurant-management-system.git](https://github.com/so-0914/restaurant-management-system.git)
cd restaurant-management-system

#### Open in IntelliJ IDEA:
- Open IntelliJ IDEA and select Open.
- Navigate to the cloned folder and open it as a Java project.
- Ensure the JDK SDK (JDK 8+) is configured in Project Structure (File > Project Structure).

#### Compile and Run:
- Navigate to src/LoginWindow.java.
- Run the main method in LoginWindow.java.
